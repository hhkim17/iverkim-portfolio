수업 소개

About the class

이 수업은 노드 기반 비주얼 프로그래밍 툴 터치디자이너를 활용해 이미지, 사운드, 움직임을 연결하는 기본 구조를 배우는 입문 과정입니다.

TOP, CHOP, SOP의 기초 개념을 기반으로 하여 비주얼을 생성하고 제어하는 원리를 이해하고, 데이터를 자신의 방식으로 변형하고 응용하는 경험을 쌓습니다.

TouchDesigner는 인터랙티브 설치, 제너레이티브 아트, 맵핑, 오디오비주얼, VJ, 소프트웨어간 연결, 네트워크 설계, 게임 제작 등 다양한 영역으로 확장될 수 있는 도구입니다. 이 수업에서는 이러한 폭넓은 가능성을 함께 살펴보고 기본기를 다지는 데 초점을 두면서 수강생이 관심 있는 방향으로 작업을 발전시킬 수 있도록 구체적인 방법과 노하우를 공유합니다.

관련 프로그래밍 경험이 없어도 수강 가능하며, 인터랙티브 아트, 미디어아트, 공연 비주얼에 관심 있는 분들에게 적합한 수업입니다. 특히 기초를 다루고 나서 심화적인 내용으로 자연스럽게 연결될 수 있도록 설계한 커리큘럼으로, 클래스가 끝난 후에도 스스로 지속적인 학습을 하시고자 하는 분들께 적합합니다.

마지막 주차에는 터치디자이너 공식 MCP를 활용해 AI와 함께 작업하는 방법도 살펴봅니다.

This introductory class explores the fundamentals of TouchDesigner, a node-based visual programming tool, focusing on how to connect images, sound, and motion within a unified system.

Based on the core concepts of TOP, CHOP, and SOP, participants will learn the principles of generating and controlling visuals, while developing the ability to transform and apply data in their own way.

TouchDesigner is a versatile tool that can be expanded across various fields, including interactive installations, generative art, projection mapping, audiovisual performance, VJing, software integration, network design, and game development. This class introduces these possibilities while focusing on building a strong foundation, and provides practical methods and insights to help participants develop their work in directions that interest them.

No prior programming experience is required. This class is suitable for those interested in interactive art, media art, and performance visuals. The curriculum is designed to move naturally from foundational concepts to more advanced ideas, enabling participants to continue developing their skills independently even after the course ends.

In the final week, we also look at working alongside AI using the official TouchDesigner MCP.

Curriculum

5주 커리큘럼

5-week curriculum

  • 회당 3시간, 주 1회씩 총 5회차
  • 개인 노트북 및 마우스 지참 필수 (권장 사양은 아래 참고)
  • 3 hours per session, once a week, 5 sessions
  • Bring your own laptop and mouse (see specs below)
WEEK 01

TOP, CHOP Basic & Feedback

  • 터치디자이너 소개와 UI
  • TOP·CHOP 기본 오퍼레이터
  • 매핑과 CHOP Reference
  • Feedback 루프, 프리셋과 .tox 저장
  • Introduction to TouchDesigner and its UI
  • Core TOP and CHOP operators
  • Mapping and CHOP references
  • Feedback loops, presets and saving .tox files
EXERCISE움직이는 캐릭터 또는 무빙 포스터Animated character or moving poster
WEEK 02

3D Render & Instancing

  • 3D 렌더 파이프라인과 PBR 재질
  • CHOP·TOP·SOP 데이터 기반 인스턴싱
  • POP Copy to Points
  • 노이즈로 만드는 인스턴싱
  • The 3D render pipeline and PBR materials
  • Instancing with CHOP, TOP and SOP data
  • POP copy to points
  • Instancing driven by noise
EXERCISE궤적을 따라 도는 행성 · 노이즈로 춤추는 3D 제너레이티브 아트Planets on a trajectory · noise-driven 3D generative visuals
WEEK 03

Point Cloud

  • 2D 이미지를 포인트 클라우드로 바꾸기 (TOP / POP)
  • Point File In으로 직접 3D 스캔한 PLY 불러오기
  • Noise·Texture 3D·Trail로 포인트 클라우드 움직이기
  • Turning 2D images into point clouds (TOP / POP)
  • Importing your own 3D-scanned PLY files with Point File In
  • Moving point clouds with Noise, Texture 3D and Trail
EXERCISE노이즈로 모핑하는 포인트 클라우드Morphing noise point cloud
WEEK 04

MediaPipe & Feedback

  • MediaPipe 플러그인 설치와 웹캠 세팅
  • 손·얼굴·포즈 트래킹 데이터를 CHOP으로 이해하기
  • Feedback 심화: Slope로 만드는 유화·수채화
  • Installing the MediaPipe plugin and setting up a webcam
  • Reading hand, face and pose tracking data as CHOPs
  • Advanced feedback: oil-paint and watercolor looks with Slope
EXERCISE내 손으로 퍼트려 그리는 웹캠 수채화 인터랙션A webcam watercolor painted with your hands
WEEK 05

Audiovisual Basics

  • 오디오 분석과 정규화
  • 버튼 모드: momentary · toggle · linear
  • CHOP Execute로 맛보는 Python
  • 터치디자이너 공식 MCP 활용해보기
  • Audio analysis and normalization
  • Button modes: momentary, toggle, linear
  • A first taste of Python with CHOP Execute
  • Trying the official TouchDesigner MCP
EXERCISE오디오 리액티브 다면체 · 나만의 VJ 시스템Audio-reactive polyhedron · your own VJ system
